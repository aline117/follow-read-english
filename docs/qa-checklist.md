# 真机手测清单（iPad）

对应 tasks 8.1–8.5、9.2、17.1–17.5、18.8、19.4.2、19.6.1–19.6.2。
一次完整走一遍约 50–70 分钟，建议**分两次**：A–E 一次（学习主流程），F–J 一次（媒体 + 备份 + 无障碍）。

记号：`[ ]` 未测 · `[x]` 通过 · `[!]` 有问题（写在行尾）。发现问题别当场改代码，先记下来——
边测边改会让后面几条的结果不可信。

## 0. 准备

- [ ] iPad 与家里电脑同一 Wi-Fi；电脑上 `serve.js`（或 `serve.py`）已启动，浏览器打开 `http://<电脑IP>:8080/` 能看到索引页
- [ ] iPad 上 App 是最新一次 Xcode Run 装上去的（7 天签名没过期：点开图标不闪退）
- [ ] 备份一份当前数据（家长 → 设置 → 备份与恢复 → 导出），测坏了能回退
- [ ] 记下开始时间：______

## A. 学习主流程（8.1）

- [ ] 选年级（二年级上）→ 单元列表出现 6 个单元，第 1 单元可点、其余有锁
- [ ] 进 Unit 1「学单词」：图片 + 单词 + 中文同时可见；进页面**不自动播放**
- [ ] 点「听一遍」出声；点图片也能出声；再点按钮文案变「再听一遍（原速）」
- [ ] 切 0.5x / 0.75x 播放正常、音调不变（变速不变调）
- [ ] 点麦克风 → 首次出说明页 → 系统授权 → 录音 → 出结果卡；结果卡能分别听「原音 / 我的录音」
- [ ] 读对：出「通过了」，有星星飘字；点「下一个」进下一个词
- [ ] 连续读错 3 次：出现「先跳过，练下一个」
- [ ] 学满 `newWordsPerDay`（默认 5）个新词：提示「今天的 N 个新词学完了」，不再给新词
- [ ] 整单元达标：发 +5 星（幂等——退出再进不会重复发）
- [ ] 「游戏」（听音选图）：4 张图、答对 +1 星、答完出结算
- [ ] 「句型」：听 → 说 → 认 三步能走完；chunks 分块显示正确
- [ ] 「复习」：当天新学的词在列表里显示「明天复习」，不是立刻复习
- [ ] 星星总数在顶部 `StarPill` 与家长面板一致

## B. 家长流程（8.2）

- [ ] 首次进家长模式要设 PIN（6 位）+ 恢复码；恢复码抄下来了吗：______
- [ ] 连续输错 PIN 会锁定（锁定时长按设计）→ 等解锁或走恢复码
- [ ] 报告页：近 7 天正确率、薄弱项、最近记录都有数
- [ ] 「评测模式」卡：设备端占比 / 兜底占比 / 今日与近 7 天识别异常次数显示正常；兜底 >50% 时出橙色提示
- [ ] 「学习趋势」卡：分段切正确率 / 时长 / 新学都有折线；缺数据的日子不出点（不是掉到 0）
- [ ] 「可疑条目」：样本 <5 的条目不出现；有数据的显示达标率与归因；导出 JSON 能分享
- [ ] 兑换规则：加一条「看 30 分钟动画 → 10 星」，孩子端能看到
- [ ] 孩子提交兑换 → 家长端出现待审核 → 通过后星星扣减、余额正确
- [ ] 拒绝兑换：星星不扣、孩子端有反馈
- [ ] 改设置（`newWordsPerDay` / 跳过阈值 / 大额二次确认）后立刻生效

## C. 防沉迷（8.3）

- [ ] 学满 20 分钟：提示「今天学完了，明天再来」，不再发星（已发的星星保留）
- [ ] 星星余额到 500：不再发新星，提示去兑换
- [ ] 把 iPad 系统时间往前调一天再进：不额外获得配额（时间回拨防护）
- [ ] 把时间调回来：数据没有错乱、复习日期没跳

## D. 多档案隔离（8.4 / 19.4.1）

- [ ] 家长端加第二个孩子，切换后：学习进度、星星、报告、观看记录**全部**独立
- [ ] 孩子 A 学 20 分钟用满后切到孩子 B：B 仍可正常学（预算是 Profile 级）
- [ ] 媒体缓存是设备级共享：B 不用重新下载 A 下过的视频
- [ ] 删掉孩子 B：B 的数据清空，A 的数据完好
- [ ] 孩子端「换人」入口不需要家长 PIN（设计已明确：切换本身不涉及家长权限）

## E. 内容分发（8.5）

- [ ] 电脑上停掉服务 → App 进内容页显示空态/指引，**不是**白屏或转圈卡死
- [ ] 重新启动服务 → 点重试能拉到 `manifest.json`，列出学期包大小
- [ ] 首次下载：弹本地网络权限 → 允许 → 下载进度 → 校验 → 安装完成
- [ ] 拒绝本地网络权限：给出「去设置」指引，不是静默失败
- [ ] 下载中杀进程再进：不产生半个学期包（要么没有、要么完整可用）
- [ ] 飞行模式 + 已装学期：单词/句型/复习全部可离线用（只有媒体串流会失败）

## F. 媒体端到端（17.1–17.5）

- [ ] 「听和看」入口：儿歌 / 绘本两个分区都能进；没有 `media.json` 时入口隐藏
- [ ] 点一个未缓存的绘本：8 秒内起播；超过 8 秒显示「正在加载」而不是黑屏
- [ ] 播放中拔 Wi-Fi：已缓冲部分继续；断了给提示，不假装在播
- [ ] 绘本逐句跟读：听原声 → 录 → 判定 → 下一句；同一句重复通过只发一次星
- [ ] 儿歌「跟读这 2 句」：只出现标注的 2–3 句，不是整首
- [ ] 播放位置续播：看到一半退出，再进从原位置继续；最后 5 秒内退出视为看完、下次从头
- [ ] 家长端「今天看了什么」：条目、累计时长、跟读通过数都对得上
- [ ] 家长端媒体明细：「通过 x/N · 一次通过 y/N · 复读 z 次」，**没有**排名/好坏评语/红黄绿标
- [ ] 设每日上限 5 分钟：看满后软拦截提示，第二天恢复
- [ ] 缓存上限设 1 GB：超了按 LRU 清理，正在看的那个不会被删
- [ ] 断网 + 无缓存：提示「连不上家里电脑」，不是无限转圈
- [ ] 改学期包 `contentVersion` 后家长端出现「有新版本」卡片 → 更新成功 → 「回退上一版」可用

## G. 备份与恢复（18.8）— **会清数据，先导出**

- [ ] 家长端「立即备份」→ 电脑 `content-service/backups/<deviceID>/` 出现 json；`/backup/index.json` 能看到这条
- [ ] 备份后立刻再点一次：内容 hash 未变 → 不重复上传（日志里能看出跳过）
- [ ] 「从家里电脑恢复」：列表有索引、显示时间与大小 → 选一份 → 二次确认 → 恢复成功
- [ ] 卸载 App → 重装 → 首次启动没有数据 → 用「从家里电脑恢复」拉回来：进度、星星、徽章、观看记录都在
- [ ] 恢复后提示「PIN 需重设」，重设后家长模式可进
- [ ] 恢复后提示缺失学期 → 重新下载 → 学习可继续（进度按条目码接上）
- [ ] 用「导出 JSON」走分享面板存到文件 App；改坏其中一个字段再导入 → 被拒绝，**数据没变**
- [ ] 电脑上把某份备份改一个字节 → 恢复时 sha256 校验失败 → 拒绝且数据不变

## H. 无障碍（9.2 / 19.6.1–19.6.2）

- [ ] 设置 → 辅助功能 → VoiceOver 打开，进「学单词」：依次读出「图片」→ 英文单词 →「中文意思：…」（顺序不能乱）
- [ ] 图片元素提示「点两下播放读音」，双击真的播
- [ ] 跟读出结果时**主动播报**「通过了。…」或「还差一点。…」，不用手动滑
- [ ] 结果卡里结论在建议之前读出；图标不被念成「checkmark seal fill」
- [ ] 句型页三个胶囊读成「流程：听、说、认，正在说」这样一句，不是三个孤立字
- [ ] 听音选图：答对/答错除颜色外还有勾/叉图标；选项朗读带「正确答案 / 选错了」
- [ ] 设置 → 辅助功能 → 减弱动态效果 打开：点阵动画、麦克风呼吸、星星飘字都不再抖，但仍能看出状态变化
- [ ] 星星飘字出现时随便点屏幕：立刻消失，且不影响下面的按钮
- [ ] 手指粗测：所有可点元素 ≥ 44×44pt（尤其返回、配速三档、「先跳过」）
- [ ] 色弱模拟（设置 → 辅助功能 → 显示与文字大小 → 色彩滤镜 → 灰度）：仍能分辨通过/未通过、已达标/未达标

## I. 提醒（19.4.2）

- [ ] 设置页「提醒」：默认关；打开「每日学习提醒」并把时间设成 2 分钟后 → 到点收到本地通知
- [ ] 通知文案**不含**任何学习明细（不写学了几个词、正确率）
- [ ] 关掉提醒 → 不再收到
- [ ] 打开「学完给个提示」→ 学满 20 分钟收到一次；同一天不重复
- [ ] 系统里拒绝通知权限：App 不崩、不反复弹窗，家长端有红点/文案兜底

## J. 收尾

- [ ] 退出家长模式 → 孩子端仍正常工作
- [ ] 后台杀进程再进：当前选中档案、星星、进度都对
- [ ] 连续用 20 分钟无闪退、无异常发热（发热明显要记下来）
