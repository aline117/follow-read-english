# 家长 runbook（日常使用与救数据）

给家长看的操作手册，不涉及代码。设计依据见 `openspec/changes/ipad-elementary-english-learning/design.md`；内容侧（加素材、打包）看 `docs/media-runbook.md`。

## 1. 装好之后先做三件事

1. **下内容**：家长模式 → 内容管理 → 地址默认就是 `http://192.168.1.11:8080` → 连接 → 下载「二年级上」
2. **建档案**：写上孩子名字、选年级；多娃就建多个档案，切换在家长 Tab
3. **设 PIN**：家长模式第一次进入时设置。PIN 和恢复码**不进备份**，重装后要重新设一次

## 2. 每天怎么用

- 孩子打开就是学习页：学单词 → 听音选图 → 句型 → 复习，一天 20 分钟封顶
- 星星够了去「奖励」Tab 兑换；提交后家长在家长模式里审核
- 家长模式能看：正确率、时长、趋势、星星流水、媒体观看明细、可疑条目（内容质量问题）

## 3. 防止孩子自己退出（建议开启）

iPad 设置 → 辅助功能 → 引导式访问 → 打开。学习时连按三下侧边按钮进入，孩子就按不出去了；退出也是连按三下（需要面容/密码）。

App 本身拦不住 Home 键与手势退出，这一步只能靠系统功能。

## 4. 备份：两条通道，主用家里电脑

| 通道 | 怎么用 | 什么时候用 |
|---|---|---|
| 家里电脑（主） | 家长模式 → 内容管理 → 「备份」卡片 → 立即备份 | 平时自动跑，不用管 |
| 导出文件（兜底） | 家长模式 → 设置与安全 → 导出备份 → 分享到「文件」/AirDrop | 出门、电脑不在家、想存一份到网盘之外的地方 |

- **自动**：App 连过内容服务后，每 24 小时最多自动传一次；学习内容没变化就跳过，不重复占空间
- **状态**：卡片上能看到「上次备份.x 小时前」和文件名；失败只在卡片上写原因，不打扰孩子
- **备份里有什么**：全部孩子的进度、明细、星星流水、徽章、兑换记录、家长配置、媒体观看状态
- **备份里没有什么**：PIN / 恢复码（安全考虑）、课文与视频（重下即可）
- **保留几份**：每台 iPad 在家里的电脑上保留最近 30 份，超出删最旧
- **存在哪**：电脑上 `content-service/backups/<设备ID>/`，**记得把它一起纳入异地备份**（体积小，价值最高）

建议：每周至少看一眼卡片上的时间是不是最近；寒暑假前后各手动点一次「立即备份」。

## 5. 恢复：换机、重装、误删

### 从家里电脑恢复（推荐）

1. 新 iPad 上装好 App、连上家里 Wi-Fi、内容管理页填好地址并连接
2. 内容管理 → 「备份」卡片 → 从家里电脑恢复 → 选一份（显示时间与大小）
3. 二次确认后整包覆盖；下载时会校验 sha256，坏了会直接拒绝
4. 恢复完会提示：PIN 需重设、备份里有但本机没装的学期要去重下

### 从文件恢复（电脑不在家）

家长模式 → 设置与安全 → 从文件导入备份 → 选 `.json` → 二次确认。

### 恢复的三条硬规则

- **整包覆盖，不做合并**：当前数据会被完全替换，不能撤销
- **校验不过不写库**：版本不符、结构缺失、JSON 损坏、校验和不符，一律拒绝，本机数据不动
- **档案 ID 沿用备份里的值**：所以恢复后星星、进度不会变成孤儿数据

## 6. 换新 iPad 的标准顺序

1. 旧 iPad 上先点一次「立即备份」（别等自动）
2. 新 iPad 装 App、连家里 Wi-Fi、连内容服务
3. 从家里电脑恢复
4. 重设家长 PIN
5. 内容管理里重下已安装的学期（备份只记了学期 id）
6. 旧 iPad 确认没用了再抹掉；别先抹再备

## 7. 排错一句话表

| 现象 | 先看这里 |
|---|---|
| 备份卡片一直失败 | 电脑上的内容服务起了吗？iPad 和电脑在同一个 Wi-Fi 吗？地址框里还是 `192.168.1.11` 吗（换路由器后电脑 IP 可能变了，看启动日志） |
| 提示「没有可用学期」 | 电脑上 `packs/` 里有没有 zip + meta；点一下「连接内容服务」重试 |
| 恢复后 PIN 不对 | PIN 不在备份里：用「重置家长 PIN」重新设 |
| 恢复后课程是空的 | 正常，课文不进备份：内容管理里重下对应学期 |
| 自动备份没跑 | 只有连过内容服务、且距上次成功超过 24 小时才会跑；回内容管理页连一次即触发 |
| 开了「每日提醒」但从不弹 | 系统里把通知关掉了：设置页那行字会变红并给「去系统设置打开通知」按钮 |
