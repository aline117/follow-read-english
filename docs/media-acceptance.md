# 媒体素材验收清单（tasks 10.8）

媒体包共 246 项（儿歌 82 / 绘本 164，6.30 GiB），全部来自外部素材，**没法靠脚本判断"能不能给孩子看"**。
水印、贴片广告、字幕错位、画面裁切这些问题只能眼睛过一遍。所以这里给一份可复用的抽检表：
每次导入新素材抽 10 条，10 分钟能过完，出问题的按条目 id 回 `media.json` 定位。

## 验收标准（每条都看这 7 项）

| 项 | 不合格的样子 | 处理 |
|---|---|---|
| 水印 / 贴片 | 出现第三方 App 水印、片头广告、二维码 | **弃用**（不能给孩子看） |
| 画面裁切 | 字幕被切掉、人物只剩半个、竖屏素材左右黑边占一半 | 弃用或换源 |
| 音画同步 | 口型与声音差 >0.3s，或整段错位 | 弃用（跟读会判错） |
| 音量 | 明显比其它条目小/大（听感差一倍以上） | 标记，考虑统一增益 |
| 时长 | `durationSec` 与实际差 >2s，或为 0 | 回写 `media.json`（不影响播放但要准） |
| 语言 | 主体不是英文（中文解说占比过半） | 弃用或标 `kind` 之外用途 |
| 收尾 | 最后 5 秒是广告/黑屏/无声 | 记录，必要时裁掉（注意：裁了 sha256 要重算） |

补充两条与跟读强相关的：

- **绘本跟读句**：句子在音轨里完整、不被切在两段之间，且没有背景音乐压过人声
- **儿歌可跟读句**：优先挑**无伴唱/清唱**片段（有伴唱时设备端识别容易整句失败，孩子读对了却判不过）

## 抽样方法（可复现）

固定随机种子，保证每次抽到的是同一批（换批次时改种子即可）：

```bash
python - <<'PY'
import json, random
m = json.load(open('content-service/media/media.json', encoding='utf-8'))
items = m["items"]
random.seed(20261108)          # 换批次就改这个数
print(f"总数 {len(items)} 项 · contentVersion {m['contentVersion']}")
for it in random.sample(items, 10):
    print(f"{it['id']:<48} {it['kind']:<8} {it['durationSec']:>6.0f}s  {it['relPath']}")
PY
```

抽完直接在 iPad 上看（手机也行）：iPad 用文件 App 打开家里电脑共享的 `media/files/` 路径，
或临时把该文件拖进「照片」。**别只看第一帧**——至少看到 1/3 处，多数问题出现在中段。

## 判定为弃用后怎么处理

1. 从 `content-service/media/files/` 删文件，并在 `media.json` 里删掉该 item（**不要**只删文件——清单留着它，App 侧会一直显示「内容损坏」）
2. `contentVersion` +1，重新跑一遍导入脚本会重算 `sha256` 与 `totalBytes`
3. 重导后跑 `python content-service/build/archive-for-backup.py --verify <归档目录>` 确认清单与文件仍然成对
4. App 侧家长端会显示「有新版本」，更新后旧缓存按 `id` 失效
