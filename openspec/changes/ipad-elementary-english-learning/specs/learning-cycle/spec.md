## ADDED Requirements

### Requirement: 课文跟读模块（跟我读）

系统 SHALL 在学习单元页提供「跟我读」入口，播放课本原声并支持逐条跟读，作为单元流转之外的课文听力练习。

#### Scenario: 连播课文原声

- **WHEN** 孩子从单元页进入「跟我读」
- **THEN** 按课本 Period 顺序连播该单元全部课文原声
- **AND** 每条音频同步展示其课本标签（如 "Listen. Then point and say"）

#### Scenario: 逐条跟读

- **WHEN** 一条课文原声播放完毕
- **THEN** 孩子可按住跟读（复用「学单词」环节的录音与评测反馈）
- **AND** 也可直接点击下一条跳过

#### Scenario: 配速播放

- **WHEN** 孩子在「跟我读」里切换配速
- **THEN** 可选 **0.5x / 0.75x / 原速**（默认原速）
- **AND** 运行时用 `AVAudioUnitTimePitch` 变速不变调，不生成或加载独立的慢速音频文件

#### Scenario: 跟读进度记录

- **WHEN** 跟读会话结束
- **THEN** 记录已跟读条数与跟读次数
- **AND** 汇入家长报告的当日学习数据
- **AND** 「跟我读」属额外听力练习，**不写入 `ItemProgress`、不参与复习调度**（与主流程内的单词/句型跟读区分开）

### Requirement: 核心学习循环

系统 SHALL 实现"学单词（听·认·说）→游戏→句型→复习"的学习循环，以听说为核心。

#### Scenario: 听音输入

- **WHEN** 孩子进入新单词学习
- **THEN** **不自动朗读**；孩子点「听一遍」（或点图片）时才播放单词发音音频（**新学默认 0.75x**）
- **AND** 展示对应图片和文字
- **AND** 支持 **0.5x / 0.75x / 原速** 三档切换，变速不变调

#### Scenario: 复习默认为原速

- **WHEN** 孩子进入复习环节
- **THEN** 默认以原速播放（检验真实语速下的辨识），仍可手动切 0.75x / 0.5x

#### Scenario: 认·说合练（单词）

- **WHEN** 孩子进入单词学习
- **THEN** 同一屏完成"看大图认词 + 听原音 + 跟读"，不再拆成听/说/认三个独立环节（**「听」就在「说」这一屏里**）
- **AND** 进页面不自动朗读，由孩子点「听一遍」播放原音（新学默认 0.75x），可切 0.5x / 原速、可反复听
- **AND** 点麦克风录音，录音上限按原音时长自动放宽（4.5-9 秒），到点自动停止
- **AND** 配速在本次「学单词」内记住最近一次选择，后续词沿用；进入复习重置为原速；录音与评测中配速控件禁用

#### Scenario: 和原音对比判定

- **WHEN** 一次录音结束
- **THEN** 用**设备端语音识别**（`requiresOnDeviceRecognition`，音频不上传）把录音转成文本，与目标词做归一化编辑距离比较
- **AND** 相似度 ≥ 0.7 且音量、时长合格 → 达标；听到的是别的词 → 未达标并提示"听到的是「…」"
- **AND** 太小声 / 没读完 → 直接未达标，不发起识别
- **AND** UI 只给定性反馈（"和原音很像 / 声音太小 / 再读一遍"），**不显示准确率百分比**

> **降级口径**：设备不支持设备端识别 / 未授权 / 识别失败时，退回「录音时长落在原音 40%-250% + 峰值音量达标」，只作兜底，不当成发音评测。
>
> **异常口径**：识别超时、音频文件读不出、录音被系统打断时，提示"再试一次"，**不写 `Attempt`**；只有评测跑完且未达标才写 `Attempt(passed=false)`。

#### Scenario: 已学与完成的口径

- **WHEN** 首页、课程列表或家长报告统计进度
- **THEN** 只有 `ItemProgress.firstPassedAt != nil` 的条目算"已学"，只产生过失败 `Attempt` 的条目不算
- **AND** 单元完成 = 该单元全部 word 与 sentence 都已首次达标
- **AND** 家长报告的"新学单词数 / 新学句型数"按当日首次 `Attempt(passed=true)` 去重统计

#### Scenario: 达标后停在结果卡，点「下一个」继续

- **WHEN** 一次跟读判定达标
- **THEN** 写入 `Attempt(kind="speak", passed=true)`、更新 `ItemProgress`，按奖励参数发星（首次达标 +3，每次达标 +2 且同一 item 每天一次，均幂等）
- **AND** **不自动跳**：停在结果卡，卡上有「听原音 / 听我的录音」，可反复对比够了再走（录音在换词前一直可听）
- **AND** 点「下一个」才进入本单元下一个未达标的词
- **AND** 本单元每个词都达标后进入下一环节（游戏）；孩子中途点「结束学习」才进结算页
- **AND** 进入学习页时固定当前单元，学完 Unit N 后不会因为首页"当前单元"变成 Unit N+1 而跳到下一单元

#### Scenario: 未达标留在本词

- **WHEN** 判定未达标
- **THEN** 停留在本词，给出可复述的提示（太小声 / 没读完 / 听到的是别的词）
- **AND** 写入一条 `Attempt(passed=false)`，不记已学、不计星
- **AND** 结果卡同样可反复听「原音 / 我的录音」，再点「再读一次」
- **AND** 连续 3 次未达标出现「先跳过」，跳过不写 `ItemProgress`、不计星

#### Scenario: 失败原因、建议配速与纠正方法

- **WHEN** 一次跟读判定未达标
- **THEN** 失败卡必须给出三段内容：一句原因、可执行的纠正建议（含建议配速）、与目标词的差异提示
- **AND** 原因按固定诊断表归类：太小声 / 没读完 / 完全听错 / 有点接近 / 读得拖 / 无法识别
- **AND** 建议配速按诊断选择（完全听错 → 0.75x；有点接近 / 没读完 / 无法识别 → 0.5x；太小声 / 读得拖 → 0.75x），并作为按钮出现，点击后才切换并播放
- **AND** 固定给出三步纠错法：`0.5x 听清 → 0.75x 跟读 → 原速读一遍`
- **AND** 差异提示展示"听到的是「…」"，并把不一致的位置归到开头 / 结尾 / 中间；多词短语指出漏掉或听错的词
- **AND** 不显示分数或相似度数值，也不做音素级评分（首版无音标与音节数据）

#### Scenario: 游戏巩固

- **WHEN** 孩子完成新词学习
- **THEN** 进入小游戏（听音选图/跟读打分）
- **AND** 正确获得星星奖励

### Requirement: 句子学习

系统 SHALL 支持每单元核心句型的学习与练习，句子与单词共用同一套学习环节、间隔重复与奖励机制。

#### Scenario: 听句子

- **WHEN** 孩子进入句型学习
- **THEN** 播放整句音频并展示英文与中文
- **AND** 支持 0.5x / 0.75x / 原速三档配速

#### Scenario: 跟读句子

- **WHEN** 孩子点击"跟读"
- **THEN** 系统录音并复用单词跟读的评测（设备端识别 + 原音对比，降级为音量/时长）判定是否达标
- **AND** 给出即时定性反馈（不显示准确率百分比）

#### Scenario: 词块排序

- **WHEN** 孩子进入句型的"认"环节
- **THEN** 系统把句子拆成词块并打乱展示
- **AND** 孩子通过拖拽把词块拼回原句，顺序正确即判定通过

#### Scenario: 听音补全

- **WHEN** 孩子进入句型的"游戏"环节
- **THEN** 播放整句音频并在文本中留一个词块空缺
- **AND** 孩子从 3 个候选词块中选出正确项

#### Scenario: 句子复习

- **WHEN** 句型到达复习时间点
- **THEN** 句型与单词一起出现在当日复习队列
- **AND** 复习完成按同一规则更新下次复习时间与掌握度
- **AND** 家长报告的"新学单词数"与"新学句型数"分开统计

### Requirement: 多感官学习

系统 SHALL 结合视觉（图片/动画）、听觉（发音/音效）、触觉（拖拽/点按）进行教学。

#### Scenario: 多感官呈现

- **WHEN** 学习新单词
- **THEN** 同时呈现图片、发音、文字
- **AND** 支持拖拽、点按等触觉交互

### Requirement: 间隔重复复习

系统 SHALL 按遗忘曲线（Spaced Repetition）推送复习内容。

#### Scenario: 复习推送

- **WHEN** 单词达到复习时间点
- **THEN** 系统在学习首页提示"需要复习"
- **AND** 复习完成后更新下次复习时间

#### Scenario: 自适应难度

- **WHEN** 孩子连续答对
- **THEN** 系统加快进度，减少重复
- **AND** 答错则增加练习次数

### Requirement: 学习单元管理

系统 SHALL 将每课拆分为 9-10 分钟的小学习单元（含 1 条核心句型）。

#### Scenario: 单元拆分

- **WHEN** 孩子选择一课
- **THEN** 系统展示多个学习单元，每个 9-10 分钟（含 1 条核心句型）
- **AND** 单元内环节顺序固定为：学单词（听·认·说合练） → 游戏(词) → 句型 → 复习
- **AND** 严格线性解锁：完成一个单元后解锁下一个，未解锁单元在课程列表中置灰、不可点
- **AND** 每日新词/新句型只从"当前已解锁单元"中取

#### Scenario: 家长手动解锁

- **WHEN** 学校教学进度超前于 App 内进度（如学校已教到 Unit 4）
- **THEN** 家长可在家长面板把指定单元标记为已解锁
- **AND** 手动解锁只放行访问，不改变星星余额与学习进度统计

#### Scenario: 继续学习

- **WHEN** 孩子点击首页"继续学习"
- **THEN** 系统直接进入"今日任务中第一个未完成的环节"
- **AND** 不单独维护"上次学到哪"的游标，也不与今日任务产生第二套顺序

#### Scenario: 卡住可跳过

- **WHEN** 同一环节连续失败 3 次（跟读未达标或连续答错）
- **THEN** 出现"先跳过"按钮
- **AND** 跳过后不记为已学、不计星，但记录一条失败明细供家长报告统计薄弱项
- **AND** 该条目顺延到下次队列，不进入复习调度

#### Scenario: 学完整册

- **WHEN** 已学条目等于总条目且当日没有到期复习
- **THEN** 首页显示"本册已学完"卡片（累计学习天数 / 总时长 / 平均正确率）
- **AND** 提供前往下载其他学期的入口，不出现空白首页

#### Scenario: 学习时长控制

- **WHEN** 孩子当日学习超过 20 分钟
- **THEN** 系统提示"今天学完了，明天再来"
- **AND** 不再获得新星星奖励
