## ADDED Requirements

### Requirement: 学习数据导出与导入

系统 SHALL 允许家长把全部学习数据导出为单个 JSON 文件，并可从该文件恢复，全程不发起任何网络上传。

#### Scenario: 导出备份

- **WHEN** 家长在「设置与安全」点击「导出备份」
- **THEN** 生成 `englishlearning-backup-<yyyyMMdd-HHmm>.json`，内含 `backupFormatVersion`、`exportedAt`、各表行数、`sha256`，以及 8 张学习状态表、家长配置（兑换规则 / 练习强度）与媒体观看状态
- **AND** 文件经系统分享面板交给家长保存，App 不上传到任何服务器
- **AND** 备份不含 Keychain 中的 PIN / 恢复码，不含课程内容与媒体缓存，也不含可由明细重建的报表快照

#### Scenario: 导入备份

- **WHEN** 家长选择一份备份文件导入
- **THEN** 先校验 `backupFormatVersion` 与逐表结构
- **AND** 校验失败（版本不符 / 结构缺失 / JSON 损坏）时拒绝导入并说明原因，不写入任何数据
- **AND** 校验通过后二次确认「当前数据将被替换」
- **AND** 确认后整包覆盖（不做合并），`Profile.id` 沿用备份中的值

#### Scenario: 恢复后的状态提示

- **WHEN** 备份恢复完成
- **THEN** PIN 与恢复码不被恢复，App 提示家长重新设置家长凭据
- **AND** 提示重新下载已安装学期（课程内容不在备份内），学习进度按 `itemCode` 与恢复内容自动对应

### Requirement: 家园局域网在线备份

系统 SHALL 支持把同一份备份上传到家园内容服务，并从该服务列取与恢复备份；服务仍只绑内网、不做端口映射。

#### Scenario: 自动备份

- **WHEN** iPad 已配置家园内容服务，且本次备份与上次成功备份内容不同
- **THEN** 距上次成功备份 ≥ 24 小时时自动上传一次
- **AND** 上传请求带 `X-Backup-Sha256`，服务端校验后以「临时文件 + 原子 rename」落盘
- **AND** 失败时静默处理并记录诊断日志，学习、复习、奖励流程不受影响

#### Scenario: 备份列表与保留策略

- **WHEN** App 请求 `GET /backup/index.json`
- **THEN** 返回该设备的备份列表（文件名、字节数、`sha256`、时间）
- **AND** 服务端每设备最多保留 30 份，超出按时间删除最旧
- **AND** 路径参数只接受 `[A-Za-z0-9-]` 与固定扩展名，拒绝任何越界路径

#### Scenario: 从在线备份恢复

- **WHEN** 家长在内容管理页选择一份在线备份恢复
- **THEN** 下载后校验 `sha256`，失败则拒绝恢复并提示「备份文件损坏」
- **AND** 校验通过后走与本地导入一致的二次确认与整包覆盖流程

#### Scenario: 备份服务不可用

- **WHEN** 内容服务未启动、设备不在同一 Wi-Fi 或请求失败
- **THEN** 备份卡片显示上次备份时间与失败原因，并提供「重试」
- **AND** 不出现阻塞式弹窗，学习流程照常可用
