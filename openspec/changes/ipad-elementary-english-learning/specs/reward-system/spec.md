## ADDED Requirements

### Requirement: 虚拟激励体系

系统 SHALL 实现多层级虚拟激励：星星、积分、徽章、等级。

#### Scenario: 即时反馈奖励

- **WHEN** 孩子答对一个问题
- **THEN** 获得星星 +1，播放庆祝音效和动画

#### Scenario: 跟读达标奖励

- **WHEN** 孩子跟读达到准确度阈值
- **THEN** 获得火焰图标 +1 和星星 +2（`grantKey = "speak:<itemCode>:<yyyy-MM-dd>"`，同一 item 每天只发一次）
- **AND** 同一单词或句型首次达标额外 +3 星（`grantKey = "first:<itemCode>"`，每个条目只发一次）
- **AND** 评测基础设施异常（识别超时 / 音频不可读 / 录音被打断）不算一次达标，不发星

#### Scenario: 单元完成奖励

- **WHEN** 孩子完成一个学习单元（该单元全部单词与句型的 `ItemProgress.firstPassedAt` 都有值，即都首次达标）
- **THEN** 获得额外星星 +5（`grantKey = "unit:<volume>-<unit>"`，幂等）
- **AND** 解锁下一个学习单元
- **AND** 首页进度条按"已学条目 / 总条目"推进（不按单元跳固定百分比）

#### Scenario: 连续学习奖励

- **WHEN** 孩子连续学习 7 天（单日累计学习 ≥3 分钟计为一天）
- **THEN** 获得"坚持小达人"徽章

#### Scenario: 质量型发星

- **WHEN** 系统发放星星
- **THEN** 触发条件必须是"有判定结果的学习行为"（跟读达标、答对、攻克薄弱词、清空到期复习）
- **AND** 不以"学满多少分钟"作为发星条件，避免磨时间

#### Scenario: 学习型奖励

- **WHEN** 孩子用星星兑换"学习型奖励"（如解锁故事时间、给头像加装扮、录朗读进作品集、当小老师）
- **THEN** 兑换成功后获得的是"更多学习内容或展示机会"，而不是"离开学习的时间"
- **AND** 与家长确认流程一致

#### Scenario: 储蓄目标

- **WHEN** 孩子查看大额奖励（≥300★）
- **THEN** 显示储蓄进度条（已存 / 目标）
- **AND** 不允许用随机抽奖替代确定性进度

### Requirement: 现实兑换机制

系统 SHALL 支持家长设置虚拟星星到现实奖励的兑换规则。

#### Scenario: 家长设置兑换规则

- **WHEN** 家长在家长端设置规则（如"100星星=30分钟动画片"）
- **THEN** 孩子可在兑换页面看到可兑换的奖励
- **AND** 显示当前星星余额和目标差距

#### Scenario: 兑换申请流程

- **WHEN** 孩子申请兑换奖励
- **THEN** 家长收到审核通知
- **AND** 家长确认后扣除相应星星并记录

### Requirement: 防沉迷控制

系统 SHALL 实施防沉迷机制。

#### Scenario: 每日学习上限

- **WHEN** 孩子当日学习超过 20 分钟
- **THEN** 系统停止发放新星星
- **AND** 允许无奖励复习

#### Scenario: 兑换冷却期

- **WHEN** 孩子兑换某项奖励
- **THEN** 同一奖励 3 天内不可再次兑换

#### Scenario: 星星上限

- **WHEN** 孩子星星超过 500
- **THEN** 系统提示兑换，不再获得新星星
